# Lagrange_interpolating_polynomial

Проект позволяет аппроксимировать произвольную непрерывную функцию с помощью кусочных интерполяционных многочленов Лагранжа и оценить качество аппроксимации.

В программе реализуются следующие шаги:
1. Задание параметров интерполяции:
   - Концы отрезка [a, b]
   - Количество интервалов K, на которые разбивается отрезок (чтобы избежать ограничений на количество узлов)
   - Степень интерполяционных многочленов Лагранжа N
   - Количество точек визуализации M_vis

2. Построение сетки:
   - Вычисление общего количества узлов M
   - Построение равномерной сетки с шагом h

3. Локальная интерполяция:
   - Построение многочленов Лагранжа на локальном отрезке
   - Вычисление значений многочлена в точках локального отрезка

4. Анализ погрешности:
   - Вычисление абсолютной и относительной погрешностей с шагом h/100
   - Использование трех различных норм векторов (сумма модулей, корень из суммы квадратов модулей, максимум модуля)

5. Визуализация:
   - Построение графиков исходной функции (сплошная линия) и многочлена (пунктир)
   - Выделение узлов интерполяции цветом, при этом концы отрезков выделяются другим цветом
   - Использование равномерной сетки из M_viz точек
